## 📋 Giới thiệu

Thư mục này chứa các hình ảnh minh chứng kết quả thực hiện các bài thực hành React Native trong Tuần 05.

Các bài thực hành tập trung vào Navigation và xử lý dữ liệu giữa các màn hình.

---

## 📝 Minh chứng các bài thực hành

### Bài tập 1 – Select Phone

Ứng dụng chọn điện thoại và màu sắc.

- Màn hình hiển thị thông tin điện thoại.
- Chọn màu điện thoại.
- Truyền màu đã chọn sang màn hình chi tiết.

### Bài tập 2 – Gắn API

- Tạo API bằng MockAPI.
- Gọi API và hiển thị dữ liệu trong ứng dụng.

### Bài tập 3 – Bottom Tab Navigation

Tạo ứng dụng có 3 màn hình:

- Home
- Search
- Profile

### Bài tập 4 – Stack + Tab + Passing Params

- Kết hợp Stack Navigation và Tab Navigation.
- Hiển thị danh sách sản phẩm.
- Chọn sản phẩm để xem chi tiết.
- Truyền dữ liệu sản phẩm giữa các màn hình.

### Bài tập 5 – Drawer Navigation

Tạo Drawer Menu gồm:

- Home
- Profile
- Settings
