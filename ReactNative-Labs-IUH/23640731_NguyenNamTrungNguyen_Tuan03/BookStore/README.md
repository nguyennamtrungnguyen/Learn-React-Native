## 📱 Giới thiệu

Thư mục này chứa các hình ảnh minh chứng kết quả thực hiện các bài thực hành React Native trong **Tuần 03 - 04**.

Các bài thực hành tập trung vào việc xây dựng giao diện ứng dụng **BookStore** bằng **React Native + TypeScript**, bao gồm Header, Book Card, Category Chips, Grid sản phẩm, Badge giảm giá, Floating Cart Button, Home Screen, Book Detail, Bottom Tab và Cart Screen.
